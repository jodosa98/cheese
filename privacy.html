チーズ (Cheese) 개인정보처리방침

최종 수정: 2026-09-15 · 운영자: 쬬도사 (개인) · 문의: tjrwnscjswp@gmail.com

チーズ는 일본의 시구정촌 방문 기록을 지도에 표시하는 개인 제작 앱입니다. 이 문서는 앱(웹, Android)이 어떤 정보를 다루는지 설명합니다.

1. 수집하는 정보

로그인하지 않으면 아무 정보도 서버로 보내지 않습니다. 사용자가 칠한 기록은 사용자의 기기(브라우저 저장소)에만 저장됩니다.

Google 계정으로 로그인을 선택한 경우, Firebase Authentication을 통해 Google 계정의 고유 ID·표시 이름·이메일 주소를 받고, 사용자가 칠한 방문 기록(시구정촌 코드와 단계, 수정 시각)을 Firebase Firestore(Google Cloud, 서울 리전)에 저장합니다. 위치 정보, 연락처, 광고 식별자 등은 수집하지 않으며 광고나 분석 도구를 사용하지 않습니다.

2. 이용 목적

여러 기기에서 같은 기록을 이어서 볼 수 있게 하는 동기화 목적으로만 사용합니다. 제3자에게 제공하거나 판매하지 않습니다.

3. 보관과 접근 권한

기록은 사용자 본인만 읽고 쓸 수 있도록 서버 보안 규칙으로 제한되어 있으며, 전송 구간은 HTTPS로 암호화됩니다. 사용자가 삭제하기 전까지 보관됩니다.

4. 삭제 방법

앱 안에서 로그인한 뒤 「계정 삭제」 버튼을 두 번 누르면 클라우드에 저장된 기록과 계정 연결이 즉시 삭제됩니다. 기기 안의 기록은 「전체 초기화」로 지울 수 있습니다. 직접 삭제가 어려우면 위 이메일로 요청해 주세요. 확인 후 7일 이내에 삭제합니다.

5. 아동

이 앱은 특정 연령을 대상으로 하지 않으며 아동의 개인정보를 의도적으로 수집하지 않습니다.

6. 변경

방침이 바뀌면 이 페이지에 수정일과 함께 게시합니다.
