# チーズ (Cheese)

일본 47개 도도부현 · 1,898개 시구정촌을 여섯 단계(거주 · 숙박 · 체류 · 경유 · 통과 · 미답)로 칠해
나만의 방문 지도를 만드는 웹 앱입니다. 설치 없이 브라우저에서 바로 쓰고, 폰에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

- 검색: 한자 · 히라가나 · 한글 · 로마자 모두 지원
- 기록: 브라우저에 자동 저장, Google 로그인 시 기기 간 동기화(Firebase)
- 업적: 방문 수·숙박 수·지방/현 완주·특별 업적 등 85개 배지
- 시구정촌별 방문일·메모, 변경 기록·되돌리기
- 내보내기/가져오기: JSON 파일

## 출처
- 행정구역 경계: 「国土数値情報（行政区域データ）」（国土交通省）を加工して作成 (2025-01-01 기준 행정구역, 표시용으로 경계 단순화)
- 독도(獨島): 원본 데이터에 포함된 독도 폴리곤은 대한민국 영토이므로 제거했습니다. 바다 이름은 표시하지 않습니다.
- 읽기(가나): 「全国地方公共団体コード」（総務省）を加工して作成
- 단계 이름과 기준은 이 앱이 독자적으로 정한 것입니다. 방문 경험을 단계로 칠하는 발상 자체는 일본에서 널리 쓰이며 [都道府県市区町村](https://uub.jp/kkn/)의 経県値®가 대표적입니다(経県値는 해당 사이트의 등록상표, 이 앱은 무관한 개인 제작물).
- 라이브러리: D3.js, TopoJSON (ISC) · Firebase (Apache-2.0)
